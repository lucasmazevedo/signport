# SignPort governance — founder-led

Founder and initial lead maintainer: Lucas Azevedo. Initial repository: the founder's personal GitHub account, repository `signport`, default branch `main`. The GitHub username is not assumed. Copyright ownership is a separate legal decision.

The maintainer approves architecture and licensing ADRs, security-sensitive changes and releases. Contributors propose changes through issues and pull requests. DCO 1.1 is proposed; contribution rights must be confirmed. No mandatory telemetry or central service. Community and managed hosting can coexist.

Start privately until rights, notices and brand review are resolved. Public pre-alpha documentation may precede production readiness. As maintainers and community grow, a transfer to an independent organization may be approved, with updated links, package ownership, credentials and release permissions. Protect main and require CI; avoid a mandatory second reviewer until there is a second maintainer.
